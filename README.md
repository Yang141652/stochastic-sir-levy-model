## stochastic-sir-levy-model

Numerical simulations for a stochastic SIR model with correlated Brownian noise and tempered stable Lévy jumps, supporting the manuscript entitled "Joint stochastic modeling of epidemic dynamics driven by Brownian motion and tempered stable noise".

Script-to-Figure Mapping

- jia2026joint_Fig2_regime_map.py → Figure 2 (dynamical regime map)
- jia2026joint_F3_rates.py → Figure 3 (decay rates)
- 01_disease_persistence.R → Figure 4(a)
- 2.py → Figure 4(b) (long-term time averages)
- big noise.R → Figure 5 (simulations under large noise intensity)
- PRCC.py → Figure 6 (PRCC analysis)

## Instructions for Reproducing the Figures

### Figure 2

First, generate the numerical data for the sample paths:


python jia2026joint_S79_F3a_inset_paths.py


Then generate the regime map:

python jia2026joint_Fig2_regime_map.py


### Figure 3

First, run the Monte Carlo simulations and numerical validation:

python jia2026joint_S30_WUN2a.py

Then generate the decay rate figure:

python jia2026joint_F3_rates.py

### Figure 4(a)


Rscript 01_disease_persistence.R


### Figure 4(b)


python 2.py


### Figure 5


Rscript "big noise.R"


### Figure 6


python PRCC.py


## Numerical Data and Reproducibility

The numerical data underlying the figures are generated by the corresponding simulation scripts. The model parameters, initial conditions, numerical schemes, and simulation settings are specified in the source files to facilitate reproducibility of the numerical results.

The scripts 1.R and the reference simulation modules provide additional numerical simulations and supporting calculations for the stochastic SIR model.
